# Obsidian + Claude Code 个人知识系统

把碎片化的「读过 / 听过」沉淀成一张**越滚越大的知识网**——用 [Obsidian](https://obsidian.md) 存笔记，用 [Claude Code](https://claude.com/claude-code)（靠 `CLAUDE.md` + 几个自定义 skill）当助手。

一条铁律贯穿全系统：**人是主体，AI 只做机械活**（取文 / 转写 / 总结 / 记账），**绝不替你下结论**。知识的复利长在你脑子里，不在 AI 的输出里。

> **这套挑人**：想要"AI 直接给答案、替我总结好"的，它会让你别扭；想要"有个东西陪我往深里想、又不替我偷懒"的，正合适。

> 这是 Frank 自己每天在用的系统骨架。你可以 **fork 来用**——照搬骨架、填你自己的个人层，就能跑。
> 想知道「为什么这么设计」，看 [DESIGN.md](DESIGN.md)。

## 它解决两个具体的痛

| 痛 | 这套系统怎么治 |
|---|---|
| 读了一堆东西，越积越多、越积越散，**用不上** | 每份新内容都去**接进**已有的笔记网——连接本身就是产物，越往后能接上的越多（这就是「复利」）。 |
| **不知道每天该学什么 / 干什么** | 从「我是谁」推出方向，落成一张**一眼能扫的行动板**，你对着它自己挑今天干哪件。 |

## 跑起来是什么样（一个真实流程）

假设你刷到一个想吸收的播客 / B站视频 / 长文：

```
1. 你把链接丢给 Claude        →  vault-ingest skill 自动接住
2. 取文                       →  转成带时间戳的 Markdown 逐字稿，存进库（原材料，只读）
3. 双总结                     →  ① 结构式（拆成"形状"，方便检索）
                                 ② 叙述式（顺着原文走一遍，留论证脉络）
4. Opus 播一张「浅图」         →  列出：这内容哪里可以再补、它和你库里"哪几篇老笔记"可能有关联
5. 你和 AI 用 /tree 顺着浅图聊 →  把聊出来的岔枝挂住、护住主线，往深里探
6. 产物按形状自动分流：
     · 关联是真的   → 笔记之间建 [[双链]]
     · 一轮聊不完的新坑 → 进"驱动层"行动板，成为以后的研究方向
     · 关联是假的   → 删掉（杀掉一个假连接也是收获）
   ↓
下次你从"连得更密的那版库"出发 —— 这就是知识复利。
```

## 两个循环（大白话版）

整套系统就是两个循环咬在一起。深层推导在 [DESIGN.md](DESIGN.md)，这里给最短的版本：

**① 学习循环** —— 内容进来，沉淀成连接。
就是上面那个流程：`链接 → 逐字稿 → 双总结 → 浅图 → /tree 往深探 → 关联分流`。核心是**别让新内容孤零零躺着，要把它接进网里**。

**② 计划循环** —— 让你学的方向不发散。从慢到快五层：

- **北极星**（`00_Self/自我画像`）：你是谁、要去哪。几乎不动，是整个系统的根。
- **成长计划**：把"我是谁"翻成几个**战略赌注**（押哪几个方向、为什么）。
- **各 plan**：某个方向的具体执行细节。
- **驱动层**（`01_Plan/`）：一张**薄板**，每个在做的 plan 占一行（卡在哪 + 下一步）。你扫这张板、自己挑今天干啥——**AI 只把板维护准，绝不替你挑**。
- **流水账**：做完的成果按时间记一行，一个产出索引。

两个循环在**驱动层**交汇：计划循环挑出任务，学习循环跑出新缺口又回填到板上。

## 快速上手

**前置**：[Obsidian](https://obsidian.md) + [Claude Code](https://claude.com/claude-code)。

1. **Fork / clone 本仓库**，把它当作你的 Obsidian vault（或把内容并进现有 vault）。`.claude/skills/` 里的几个 skill 会被 Claude Code 自动加载，**不用额外安装**。
2. **在这个目录打开 Claude Code，说一句"我是新来的"**（或 `start` / `怎么开始`）。`start` skill 会接住你：把系统讲清楚 → 看适不适合你 → 问你名字、把这套改成你的 → 再带你做第一件真东西：**建你的自我画像**（系统的根）。
3. **之后就跑两个循环**：丢链接给 Claude → 走学习循环；扫驱动层、对着战略赌注挑今天干啥 → 走计划循环。

> 慢一点是对的。这套不替你思考——画像、连接、判断都得你自己动脑挖。它降的是"不知道怎么开始"的门槛，**不降"自己构建知识"那份功夫**。
>
> 文档和示例里的 **"Frank" 是示范用户**，保留他是为了让你看到一套**真在运转**的系统长什么样；`start` 第一次跑时会把配置里的 Frank 换成你的名字。
>
> （`vault-ingest` 的音视频转写还需要 `yt-dlp` / `ffmpeg` / `whisper-ctranslate2`，只吸收纯文章用不到。）
