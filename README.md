# obsidian-claude

一套基于 Obsidian + Claude Code 的个人知识管理工作流，核心目标是让每次学习产生**知识复利**。

---

## 为什么做这个

大多数笔记系统从"学什么"出发，结果是文件越来越多，但和自己的关系越来越模糊。

这套系统从**自我画像**出发：先搞清楚自己是什么样的人、想往哪个方向走，再由此派生出成长计划，再拆解成具体的 Plan。学习方向不是随机积累，而是从自我认知里长出来的。

有了方向之后，才是输入和消化的问题。而这里也有第二个问题：**光读不够，没有机制逼出真正的理解**。

这套工作流在"存"之外加了一个环节：用 AI 苏格拉底式提问，把你读到但没真正消化的东西逼出来，再写回笔记。下次读同一个话题，起点已经是被训练过的版本。

这就是复利的来源。

这套系统里，**AI 是辅助，不是替代**。AI 可以快速帮你处理原材料——总结结构、提炼要点——让知识迅速进入上下文，你不需要每次重新给 AI 喂背景。但 AI 总结之后，你还是要自己读。读的过程中可以边问边记，把疑问和想法沉淀下来。最终形成的是你自己的总结，而不是 AI 的转述。有了这份自己的理解之后，再用 `/train` 跑通，才算真正消化。

---

## 工作流

```
00_Self — 自我画像 + 成长计划
        ↓
  确定学习方向和 Plan
        ↓
01_Inbox — 输入原材料（书、播客、文章）
        ↓
02_Work — 自己消化，写笔记
        ↓
/train — AI 苏格拉底式提问，暴露理解盲区
        ↓
产生新洞见，写回原笔记
        ↓
下次训练，从更高的起点出发
        ↑_________________________________↑
                    知识复利
```

整个系统以 **Self 为起点**：不是"我应该学什么"，而是"我是什么样的人，因此我选择学什么"。学习方向从自我认知里派生，不是随机积累。

---

## 文件夹结构

```
你的知识库/
├── 00_Self/        自我画像 + 成长计划，整个系统的根
├── 01_Inbox/       原始材料，只读不改，用于溯源
├── 02_Work/        自己消化后的笔记、分析、框架
└── 03_Wiki/        反复验证后提炼的可迁移框架
```

**分层的核心逻辑**：原材料和自己的理解严格分开，防止把别人的观点当成自己的判断。03_Wiki 的框架必须经过多次训练验证才能写入，不能由 AI 直接生成。

## /train Skill

这套工作流最核心的部分。

`/train` 是一个 Claude Code skill，让 Claude 扮演苏格拉底式学习伙伴——它不替你总结，不考你记忆，只问能逼出思考的问题：

> "你同意这个判断吗？有没有反例？"  
> "这个逻辑再推一步会得到什么？"  
> "这个现象背后的机制是什么？"

训练结束后，你可以把这次对话里产生的新洞见追加到原笔记，下次 `/train` 读到的是被训练过的版本。

**安装方法：**

1. 下载 [`skills/train/SKILL.md`](./skills/train/SKILL.md)
2. 打开 Claude Code → 上传 skill 文件
3. 在任意对话里输入 `/train` 即可启动

**触发方式：**

```
/train
来考考我
练习一下这篇笔记
基于这个文档问我问题
train me on this
```

## 配合 CLAUDE.md 使用

在知识库根目录放一个 `CLAUDE.md`，定义你的文件夹结构和命名规范。Claude 读取后会自动把笔记存到正确的位置，不需要每次手动指定路径。

本仓库的 `CLAUDE.md` 可以直接作为起点，按自己的习惯修改。
