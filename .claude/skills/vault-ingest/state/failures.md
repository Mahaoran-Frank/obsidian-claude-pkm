# 失败台账 (failures) — 暂时搞不定的，等升级

> 这不是垃圾桶，是这个 skill 的成长清单。每条都是下次进化的种子。
> 格式：日期 ｜ 链接/类型 ｜ 卡在哪一步、为什么 ｜ 要我以后能搞定，需要用户/我们提供什么
>
> 解决后 → 把它从这里搬进 recipes.md（晋升）。

## 已知的硬限制（第一版就预告过）

- **Spotify 独占音频**：DRM，yt-dlp 扒不了 → 只能换源（找该节目的 Apple/RSS 入口）。
- **登录/付费墙内容**（部分公众号、X 长推、付费播客）：需要 cookie。
  解决路径：用户导出该站点 cookie（Netscape 格式），脚本加 `--cookies <file>`。
- **whisper 转长中文音频慢**：不是搞不定，是慢。可换 `WHISPER_MODEL=large-v3-turbo` 提速。
